# Course Index — By Category

An overview of every module (lesson) across all courses, grouped by pedagogical category
and ordered by increasing difficulty (`courseb` → `coursec` → `coursed` → `coursee` → `coursef`,
oldest year first within the same course). Click a module's name to jump straight to its
first puzzle file.

See also: [INDEX_BY_MAZE_TYPE.md](INDEX_BY_MAZE_TYPE.md) — the same modules grouped by maze/character theme instead.

> Some code.org lessons use licensed IP (e.g. Ice Age, Star Wars) that cannot be re-imported
> into this repo due to artwork licensing. Those modules are listed with a note and no link.
