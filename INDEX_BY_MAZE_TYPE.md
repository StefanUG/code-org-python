# Course Index — By Maze Type

An overview of every module (lesson) across all courses, grouped by the maze/character theme
that dominates it (based on the actual player class used, e.g. `Bird`, `BeePlayer`, `Farmer`,
`Harvester`, `Collector`, `ZombiePlayer`), and ordered by increasing difficulty
(`courseb` → `coursec` → `coursed` → `coursee` → `coursef`, oldest year first within the same
course). Click a module's name to jump straight to its first puzzle file.

See also: [INDEX_BY_CATEGORY.md](INDEX_BY_CATEGORY.md) — the same modules grouped by pedagogical category instead.

> Some code.org lessons use licensed IP (Ice Age, Star Wars) that cannot be re-imported into
> this repo due to artwork licensing. Those modules are listed in the "Not yet available"
> section below instead of a themed group.
